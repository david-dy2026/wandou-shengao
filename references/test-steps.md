# 试用步骤与结果检查

装了之后，先别拿重要稿子试。找一段自己已经发过、效果一般的内容，最好是你知道读者在哪一句走的。

## 一、试一轮

```text
使用 $wandou-shengao，用四视角审一下下面这段稿子。
受众：想做自媒体但还没开始的上班族。
（粘贴稿子）
```

## 二、看它交的东西对不对

按这四条对，不对就退回去：

| 检查项 | 对的样子 | 不对的样子 |
| --- | --- | --- |
| 有没有引用原文 | 每条都带「」引一句原话 | 通篇"有些地方""整体感觉" |
| 原因说得具体吗 | 指出是哪个词、哪一步逻辑 | "不够吸引人""可以更生动" |
| 给的是替换句还是方向 | 能直接粘回去的一整句 | "建议更具体""可以加个例子" |
| 四个视角有没有串味 | 四个人说的明显不是同一件事 | 四条意见读起来像一个人写的 |

四条都对，这份审稿能用。任意一条不对，加一句"第 X 条重新给，必须引用原文并给出可替换的整句"，再跑一次。

## 三、看它有没有把稿子改坏

改后整稿那一段最容易出问题。对一下：

- 语气还在不在。原来像在说话，改完像不像在念范文。
- 该删的删了，"因为所以但是只是"少了没有。
- 没被点出来的地方有没有被动过。动了就是越界，让它恢复。
- 加进去的内容有没有你自己没说过的事实。有，一律删掉。

## 四、只跑一轮的意义

第一轮通常能抓出三四条真问题，这些占了大部分收益。

第二轮专门改第一轮漏的，收益明显变小。第三轮之后基本是在换措辞。两轮到三轮就该发出去，看真实反馈，比在屋里挑第八遍有用。

## 五、什么时候不该用这个 Skill

- 稿子还没写。先写，再审。
- 只是想把句子改顺。那是润色，不是审稿，用它只会把稿子改散。
- 你心里已经决定要发了。这时候审稿只会给你添堵，不如直接发出去收反馈。
